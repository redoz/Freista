Data-port glyph — pick the one that reads best

Where an object-flow edge meets a step, we mark a port: input on the top edge, output on the bottom edge, colored per object type. The current diamonds () underwhelm. Below: four candidates, each in context (green edge reads in on top, pink edge creates out the bottom) with a 3× zoom. Click your pick.

Hollow ring receives; solid disc with a faint halo emits. Clean, modern, reads like a connection handle in a node editor.

A socket cut into the edge that the edge plugs into; output is a plug pin pushing out. Most literally a "data port," but more drawing per node.

A small rounded tab straddling the edge — outline = input, filled = output. Bigger hit target, but competes visually with the object cards (which are also rounded rects).
